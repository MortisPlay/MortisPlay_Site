# Mortis Play — Официальный сайт v3.0

**Йоу, геймеры!** 🎮🔥  
Добро пожаловать на обновлённый официальный сайт **Mortis Play** — современное, стильное и функциональное пространство для всего нашего комьюнити. Версия 3.0 превращает сайт в полноценную платформу: здесь появились **аккаунты, монеты, магазин оформления профиля, бейджи, зал комьюнити с мемами** — и всё это работает на собственном серверном бэкенде (Node.js + Express + SQLite).

## 🚀 Что нового в версии 3.0?

### 👤 Аккаунты и профили
* **Регистрация с подтверждением почты:** Код подтверждения отправляется на email через **EmailJS**, без подтверждения аккаунт не активируется.
* **Личный профиль:** Имя, уникальный `username`, смена email, сброс пароля, настройки.
* **Персонализация:** Загрузка своего аватара, аватары из магазина, анимированные рамки-ауры и бейджи вокруг профиля.
* **Безопасные сессии:** Авторизация через токены (Bearer), срок жизни сессии — 7 дней, пароли хэшируются через `scrypt` + соль.

### 🪙 Монеты, награды и магазин
* **Валютная система:** Каждый новый пользователь получает **1000 стартовых монет**.
* **Награды за просмотры:** Авторизованные зрители получают монеты за полный просмотр роликов YouTube (`/api/videos/reward`), история начислений хранится в профиле.
* **Магазин** ([`shop.html`](shop.html)): Эксклюзивные аватарки, рамки-ауры (Золотая, Неоновая, Огненная, Космическая, Кристальная, Королевская).
* **Лутбоксы:** «Стартовый кейс» — случайный приз с шансами на редкие предметы (`/api/shop/open`).
* **Ограниченные выпуски:** Серия эксклюзивных аватарок лимитом **10 штук** — после распродажи исчезают навсегда.
* **Админ-панель:** Выдача монет и бейджей через серверные эндпоинты `/api/admin/*` с проверкой секретного кода.

### 🎭 Зал комьюнити
* **Галерея мемов** ([`community.html`](community.html)): Неоновый киберпанк-зал с GIF, картинками и видео от сообщества.
* **Загрузка своих мемов:** Перетащите файл или вставьте ссылку — мем мгновенно появится в галерее (нужен вход в аккаунт).
* **Хранение больших файлов:** Загруженные мемы сохраняются в **IndexedDB** (видео до 100 МБ, картинки до 15 МБ) с автоматической миграцией старых записей из `localStorage`.
* **Управление:** Просмотр в лайтбоксе, удаление собственных публикаций, счётчики просмотров и активности пользователей.

### 🧭 Удобство и юридическая база
* **Гид по сайту:** Интерактивный тур из 5 шагов при первом посещении (можно открыть повторно из меню).
* **Правовые документы:** Модальные окна «Политика конфиденциальности» и «Соглашение сайта» в футере.
* **Уведомления об обновлениях:** Сайт проверяет GitHub API и показывает свежие коммиты (отключается в настройках).
* **Мобильная нижняя навигация:** Быстрый доступ к основным разделам с телефона.

### 🎨 Дизайн и анимации
* **Живой фон:** Canvas-частицы, светящиеся орбы и неоновая сетка.
* **Стеклянный морфизм (Glassmorphism):** Размытие, динамические бордеры, адаптивные тени.
* **Тёмная и светлая темы:** Переключение без «мигания» — тема применяется синхронно до рендера.
* **Микроанимации:** Плавные переходы, лоадер, прогресс-бар прокрутки и кнопка «наверх».

## 🛠️ Технологический стек

### Backend
* **Node.js + Express 5:** Собственный серверный API (`server.js`).
* **better-sqlite3:** Быстрая синхронная SQLite-база данных (единый файл `data.db`).
* **crypto (scrypt):** Хэширование паролей, генерация токенов и SHA-256 для админ-доступа.

### Frontend
* **HTML5:** Семантическая разметка (`main`, `section`, `header`, `footer`, `aria-label`).
* **CSS3 & Tailwind CSS:** Утилитарные классы, адаптивная сетка (`grid`, `flex`), кастомные переменные тем.
* **JavaScript (ES6+):** `async/await`, `fetch`, ООП-классы (например, `VideoSystem`), паттерн `debounce`.
* **Font Awesome v6.5.0:** Векторные иконки.
* **Google Fonts:** Шрифты *Manrope* и *DM Mono*.

### API и Интеграции
* **Собственный REST API:** `/api/auth/*` (регистрация, вход, выход, сброс пароля), `/api/profile/*` (профиль, смена email, проверка username), `/api/shop/*` (товары, покупка, кейсы), `/api/videos/*` (награды, история), `/api/admin/*` (монеты, бейджи), `/api/notes`.
* **YouTube Data API v3:** Автообновление архива видео и статистика канала.
* **Twitch Embed API:** Стримы и клипы с привязкой к родительскому домену.
* **EmailJS:** Отправка кодов подтверждения почты при регистрации.
* **GitHub API:** Проверка свежих обновлений и история коммитов.
* **Google Analytics (gtag.js):** Отслеживание активности, кликов и событий (загрузка мемов и т.д.).

## 🎯 Инструкция для пользователей

### Для зрителей
1. Выберите тему (день/ночь) кнопкой-солнцем в шапке или в меню.
2. Зарегистрируйтесь: укажите email, имя и пароль — придёт код подтверждения.
3. Смотрите видео и клипы, получайте монеты за просмотры и тратьте их в магазине на аватарки и рамки.
4. Делитесь мемами в Зале комьюнити (для загрузки нужен вход в профиль).
5. Включайте VPN, если видеохостинг работает нестабильно (инструкция — по кнопке в разделе видео).
6. Поддерживайте проект через официальную кнопку **DonationAlerts**.

### Для разработчиков
1. Логика видео реализована в классе `VideoSystem` в [`index.html`](index.html); конфигурация — в объекте `YOUTUBE_CONFIG`.
2. Весь серверный API — в [`server.js`](server.js). Эндпоинты требуют авторизации через заголовок `Authorization: Bearer <token>`.
3. Верстка адаптивна и протестирована от смартфонов до 4K-мониторов.

### База данных и хостинг
1. На всём сайте используется **одна база данных** — SQLite-файл `data.db`. Таблицы: `users`, `sessions`, `items`, `purchases`, `video_rewards`, `notes`. Все пользовательские данные (профиль, монеты, инвентарь, бейджи) синхронизированы между страницами.
2. Сервер запускается командой `npm start` (`node server.js`). База создаётся автоматически при первом запуске, магазин наполняется сидами, а существующий `data.db` обновляется миграцией (недостающие таблицы и колонки добавляются сами).
3. На хостинге путь к базе задаётся переменной окружения: `DB_PATH=/полный/путь/data.db` (по умолчанию — `data.db` рядом с сервером). Убедитесь, что каталог доступен для записи процессу Node.js.
4. Порт задаётся переменной `PORT` (по умолчанию `3000`).
5. Админ-панель (бейджи, монеты) работает через те же эндпоинты `/api/admin/*` с проверкой SHA-256 хеша секретного кода.

### ⚠️ Важно: сайту нужен Node.js-хостинг (НЕ GitHub Pages!)
* Сайт **не является чисто статическим**: регистрация, вход, магазин, монеты, бейджи и загрузка мемов требуют серверного API (`/api/*`), который выполняет [`server.js`](server.js) (Node.js + Express + SQLite).
* **GitHub Pages, Netlify Static, Vercel Static и аналогичные статические хостинги НЕ поддерживают Node.js.** Все запросы `/api/auth/register`, `/api/auth/login`, `/api/auth/me` и т.д. будут возвращать **404**, а в консоли появится `Unexpected token '<' ... is not valid JSON`. Функции «регистрация», «вход», «магазин» и «загрузка мемов» на таком хостинге работать **не будут**.
* Для полноценной работы разместите сайт на хостинге с поддержкой Node.js: **Render.com**, **Railway.app**, **Fly.io**, **Vercel (Node.js runtime)**, VPS с Node.js (**Timeweb Cloud**, **Beget**, **reg.ru**), а также **Alwaysdata**. Запуск: `npm install && npm start`.
* Учтите: зависимость `better-sqlite3` — нативный модуль, поэтому на хостинге должна быть совместимая версия Node.js и возможность сборки (на Render/Railway/Vercel она есть по умолчанию).
* Если вы всё же разворачиваете только фронтенд (например, GitHub Pages через CNAME), аккаунты, магазин и прочие серверные функции работать не будут — нужен отдельный бэкенд.
